# 국내 기업 공시정보 기반 질의응답 서비스

### 서비스 개요

DART에 공개된 국내 상장기업의 공시를 수집/구조화하고, 사용자가 공시 내용을 이해하고 비교할 수 있도록 지원하는 서비스

목표

1. 복잡한 공시를 일정 형식으로 요약
2. 서로 다른 공시를 연결해 기업의 변화와 추이를 보여줌
3. 모든 답변에 공시 원문, 출처를 근거로 제시

### 핵심 기능

기업별 공시 조회

- 각 공시를 선택하면 원문, 핵심 요약을 보여줌

공시 요약 및 정보 추출

- LLM이 공시 유형별 형식에 따라 정리.

공시 기반 질의응답

- 사용자가 자연어로 질문하면 관련 공시를 검색, 원문 근거를 포함해 답변

기간별 비교, 변화 추적

- 단일 공시가 아닌 여러 시점의 공시를 연결해 기업의 변화를 보여줌

### 개발 범위

phase 1 - 공시 수집 및 기업 페이지

- DART 공시를 안정적으로 수집해 사용자에게 보여주는 것.
- 주요 기능
  - DART 기업 고유번호 연결
  - 공시 목록을 주기적으로 수집
  - 공시 원문 다운로드
  - 기업별 최근 공시 목록
  - 공시 상세 페이지
  - 기업별 공시 목록을 리스트로 보여줌

phase 2 - 공시 요약 및 정보 추출

- 공시를 사용자가 빠르게 이해할 수 있도록 구조화
- 주요 기능
  - 공시 유형별 요약
  - 핵심 사실 추출
  - 주요 수치 추출
  - 본문과 표 분리
  - 요약문과 원문 근거 연결
  - 추출 결과 검증

phase 3 - 공시 기반 질의응답

- 사용자의 질문에 관련 공시를 찾아 근거와 함께 답변
- 주요 기능
  - 기업명, 기간, 공시 유형 인식
  - 질문 목적 분류
  - 메타데이터 필터링
  - 공시 원문 검색
  - 여러 공시 종합
  - 근거 생성
  - 공시 원문 링크 제공

phase 4 - 기업 변화 및 비교 분석

- 공시 정보를 기반으로 기업 변화 추이를 보여줌
- 주요 기능
  - 기업별 주요 사건 타임라인
  - 사업, 전략 등의 변화 추적

### 추후 구현 (현재 범위 제외)

아래 내용은 설계만 유지하고, 당장 구현하지 않는다. 공시별 요약과 사실·수치 추출은 phase 2에서 구현한다.

- 기간별 비교, 변화 추적 (phase 4)
- Company Knowledge: 기존 기업 지식과 비교, 누적, 업데이트 로직 및 이력
- 질의응답의 Company Knowledge 조회 경로: 현재는 RAG 검색만 사용
- 변화 분석형 질문: 기간별 공시 비교, 기업 전체 변화 분석, 기업 공시 타임라인

### 데이터 수집 및 가공 과정

DART 공시 목록 API 사용

- 신규 공시 확인
- 기업, 공시일, 공시 유형 등 메타데이터 저장
- 공시 XML 원문 다운로드

공시 Parsing

- 문서 구조 분석
- XML 태그 제거 및 텍스트 정제
- 본문과 표 분리
- 문단, 항목 구조는 보존

검색 데이터 생성

- 검색 가능한 단위로 청킹
- 각 청크에 메타데이터 연결
- 임베딩 생성
- 벡터 저장소에 저장

요약 및 정보 추출

- 공시 유형 판별
- 핵심 사실, 사건, 수치 추출
- 공시 유형별 요약 생성
- 추출 결과와 원문 근거 연결

↓

├─ 주요 수치 조회
├─ 기간별 공시 비교
├─ 기업 전체 변화 분석
└─ 기업 공시 타임라인

├─ RAG

└─ Hybrid
↓

### 답변 형식

- 결론
  - 질문에 대한 답변
- 주요 내용
  - 핵심 사실, 수치, 변화 사항
- 해석
  - 공시로부터 직접 확인되는 사실과 LLM이 해석한 내용을 구분해 보여줌
- 근거 공시
  - 공시명 / 공시일 / 공시 접수번호 / 관련 원문 링크
